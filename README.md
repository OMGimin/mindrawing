# 마인드로잉

마인드로잉은 7–13세 아동의 그림에 나타난 특징을 연구·해석 자료와 연결해, 보호자가 가능한 심리적 의미를 쉽고 구체적으로 이해하도록 돕는 서비스입니다.

이 README는 2026-10-04 확정한 서비스 방향의 기준 문서입니다. 연구 사실은 [research.md](research.md), 실제 구현·검증 범위는 [site/README.md](site/README.md)에서 관리합니다. 과거 팀 프로젝트의 문제의식을 바탕으로 2026년에 새 목업을 구현했으며, 두 시기의 기술·성과를 합쳐 설명하지 않습니다.

## 문제 정의와 핵심 가치

보호자는 아이의 그림에 무엇이 있는지뿐 아니라 그 표현을 어떤 의미로 읽어볼 수 있는지 궁금할 수 있습니다. 하지만 그림 특징을 해석 자료와 연결하기 어렵고, 전문 용어만으로는 뜻과 해석의 방향을 이해하기 어렵습니다. 기존 프로젝트는 상담·검사에 드는 비용과 시간, 방문 부담이라는 문제의식에서 출발했습니다. 이를 모든 보호자에 대해 입증된 수요나 장벽으로 일반화하지 않습니다.

서비스의 핵심 가치는 결과를 읽는 것만으로 그림의 가능한 의미를 이해하는 것입니다. 객체 인식이나 특징 묘사에서 끝내지 않고, 해당 특징을 어떤 의미로 해석하는지 근거가 허용하는 범위에서 설명합니다. 상담 준비 자료를 만드는 것이 주목적은 아닙니다.

## 대상과 기본 흐름

- 대상 사용자: 7–13세 아동의 그림을 이해하려는 보호자. 이는 현재 제품 대상이며 과거 팀 자료의 연령 기록을 소급 수정하는 뜻은 아닙니다.
- 목표 경험: **그림 입력 → 특징별 가능한 의미 → 전체적으로 읽어볼 수 있는 해석**.
- 보호자 관찰 입력이나 상담용 꼬리질문은 기본 흐름의 필수 요소가 아닙니다. 메모·추가 정보는 필요한 경우 선택합니다.
- 상담기관 안내는 결과를 본 사용자가 필요에 따라 선택하는 보조 기능입니다.

## 결과 작성 원칙

각 설명은 **어떤 특징인가 → 어떤 방향의 의미로 해석되는가 → 쉬운 말로 무엇을 뜻하는가 → 출처와 적용 범위는 무엇인가**를 담습니다.

1. 추상적인 용어만 제시하지 않고 일상적인 말로 풉니다. 어떤 상태의 표현이라는 설명인지, 그 상태를 바란다는 해석인지 등 의미의 방향은 원문 근거가 허용하는 만큼 구분합니다. 구분할 수 없으면 그 부분을 명시합니다.
2. 논문이 직접 확인한 연관성, 저자가 다른 문헌에서 인용한 해석, 서비스가 이해를 돕기 위해 풀어 쓴 설명을 구분합니다. 출처 링크만 붙이거나 모든 근거를 전통적 해석으로 묶지 않습니다.
3. 연구 사실을 추가·수정할 때는 원문의 해당 구절·표·대상·조건을 확인합니다. 원문에 없는 성격·행동·동기를 덧붙이지 않습니다. 현재 예시 문구도 이 기준에 따른 개별 근거 대조가 필요하며, 기준 문서 작성만으로 검증 완료가 되지 않습니다.
4. 집단 연구 결과를 특정 아이의 상태·진단으로 확정하지 않습니다. 연구 한계는 설명과 함께 정확히 전달하되 핵심 의미 설명을 밀어내지 않도록 구성합니다.
5. 전체 해석은 특징별 설명의 관계와 확인 가능한 범위를 정리합니다. 여러 특징을 합쳤다는 이유만으로 새로운 성격·동기나 진단을 만들어내지 않습니다.

## 현재 구현과 향후 목표

| 구분 | 범위 |
| --- | --- |
| 현재 구현 | 유료 API 없는 정적 웹 목업. 집·나무·사람 그림의 로컬 미리보기, 합성 그림에 미리 작성한 의미 설명, 그림별 개요·탭, 접어 보는 근거, 선택 메모, 브라우저 내 텍스트 기록, 별도 상담기관 안내 |
| 아직 미구현 | 실제 업로드 그림의 AI 분석, 여러 특징을 통합하는 전체 해석 기능, 서버 DB·계정, 실제 상담 예약 |
| 향후 목표 | 실제 그림의 특징을 파악하고 근거에 연결한 설명과 전체 해석을 제공. 논문·데이터셋·CV·이미지 이해 방법을 비교해 발전시키며 과거 코드 복원에 묶이지 않음 |

현재 결과는 합성 그림의 고정 예시이며 등록한 그림을 해석한 결과가 아닙니다. 등록한 그림을 서버로 전송하거나 기록에 저장하지 않습니다. 고정 예시라는 제약은 현재 구현 상태이며 장기 제품 목적이나 기능 제한이 아닙니다. 목업에서도 의미 설명의 구체성·이해 가능성·사용 흐름은 충분히 완성해야 합니다.

향후 기술 선택에서는 특징 인식 성능, 해석 근거와의 연결, 설명의 충실성, 비용과 이미지 처리 조건을 구분해 검토합니다. 이미지 인식 모델 도입 자체를 심리 해석의 타당성 검증으로 취급하지 않습니다.
