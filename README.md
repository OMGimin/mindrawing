# 마인드로잉

집·나무·사람 그림에 연결해 온 의미를 쉬운 말로 살펴보는 한국어 웹 목업입니다. 과거 팀 프로젝트의 문제의식을 바탕으로 2026년에 새로 구현했습니다.

## 현재 범위

- 집·나무·사람 그림의 로컬 미리보기 또는 합성 그림 예시 체험
- 집·나무·사람 예시의 의미를 먼저 보여 주는 결과와 접어 볼 수 있는 문헌 근거
- 선택적으로 남기는 보호자 메모와 브라우저 내 텍스트 기록
- 별도 메뉴의 공식 상담 기관 안내 및 근거와 한계

실제 AI 분석·심리 진단·상담 예약·계정 및 서버 저장은 제공하지 않습니다. 등록한 그림을 서버로 전송하거나 기록에 저장하지 않습니다. 결과의 의미 설명은 합성 그림에 미리 작성한 예시이며 등록한 그림을 해석한 결과가 아닙니다.

## 실행과 검사

```sh
cd site
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 별도 빌드와 의존성 설치가 필요 없습니다.

```sh
cd site
node --test
```
